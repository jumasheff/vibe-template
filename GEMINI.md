# Directory Overview

This directory is a template for "vibe coding". It is intended to be a starting point for projects that prioritize a certain aesthetic and thoughtful approach to development. It also contains a `.claude` directory with a set of commands.

# Key Files & Directories

*   `README.md`: The main entry point for understanding the project's purpose.
*   `.claude/`: A directory containing custom commands.
    *   `commands/create-prd.md`: A command to create a Product Requirements Document.
    *   `commands/generate-tasks.md`: A command to generate tasks from a PRD.
    *   `commands/process-task-list.md`: A command to process a list of tasks.

# Usage

This directory is a template. To use it, you can copy it to a new location and start building your project on top of it. The commands in the `.claude` directory can be used to automate common development tasks.
